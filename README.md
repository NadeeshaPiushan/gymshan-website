# Gymshan website — starter package

A responsive static website concept for gymshan.com, designed around Gymshan's performance training, gymnastics programs, events, and branded gear.

## Files
- `index.html` — page content and SEO basics
- `styles.css` — responsive visual design
- `script.js` — mobile menu and WhatsApp enquiry form
- `assets/gymshan-logo.png` — Gymshan transparent wordmark (if available when this package was built)

## Preview locally
Open `index.html` in a browser. Internet access is needed for Google Fonts and the remote photography used in this first version.

## Before publishing
1. Confirm the contact number in `script.js` and the footer. It is currently set to `+94 74 076 6572`.
2. Replace the remote stock photos with approved Gymshan training, facility, athlete and product photography for a more authentic brand.
3. Confirm the real training location, schedule, pricing, booking process, social media links and event details.
4. Add a privacy notice if you collect personal data through a backend form. This starter form opens WhatsApp and does not store form submissions.
5. Connect `gymshan.com` to your chosen static host (for example, Netlify, Cloudflare Pages or GitHub Pages) using that provider's domain instructions. This package does not publish the website or change DNS settings.

## Design
Minimal dark navy / white / electric blue visual system based on the Gymshan logo supplied in the Library. The current tagline is retained as “Gears and High Performance.”
